# 📄 DocuCheck

A web-based document verification system designed to help users manage and validate digital documents.

## 🚀 Features

- 📑 Digital document management
- 🔍 Document verification
- 🗂️ Organized document storage
- 💻 Simple and user-friendly web interface
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🎯 Project Objective

The main objective of DocuCheck is to provide a simple digital platform for managing and verifying important documents efficiently.

## 📂 Project Structure

- `index.html` — Main webpage
- `DocuCheck/` — Project files
- `Digital_Library/` — Digital document resources
- `Cloud-Tiny-Project/` — Supporting project files
